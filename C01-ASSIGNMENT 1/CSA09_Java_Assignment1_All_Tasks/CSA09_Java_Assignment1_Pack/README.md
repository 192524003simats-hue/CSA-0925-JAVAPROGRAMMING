# CSA09 Programming in Java — Assignment 1 (CO1)

This pack follows the supplied assignment brief for Tasks 1–12. Each `TaskXX` folder contains an `answer.md`, a Java source file where a code demonstration is appropriate, and `output.txt` with the expected output for the included program. Tasks 1 and 2 are analysis/data-representation tasks, so their Java files are small demonstrations rather than a claim that the whole system is implemented there.

## Run programs
Install JDK 17 or newer. Open a task folder in a terminal and run:

```bash
javac FileName.java
java FileName
```

For `FeeDemo.java`, run `javac FeeDemo.java` then `java FeeDemo`. For `SmartParkingExtended.java`, run `javac SmartParkingExtended.java` then `java SmartParkingExtended`.

## Important
- Review the answers and run each program yourself before submission; replace sample name/register details if your faculty requires them.
- `output.txt` is expected output for the included source, not a screenshot of your own execution. Capture and add your own output screenshots if required.
- Task 11 and Task 12 are educational demonstrations, not a production parking system. Check the explanation and test cases against your own execution.
